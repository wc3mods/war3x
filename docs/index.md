# Warcraft 3 Expansion Mod Documentation

Warcraft 3: Expansion (War3x) is an [AMX Mod X](https://www.amxmodx.org/) plugin that brings the races, skills, ultimates and items of Blizzard's Warcraft III to Counter-Strike 1.6 and Condition Zero. These docs cover installing, configuring and playing it.

## Current Version

The current release is **1.0.5**, built for AMX Mod X 1.8.2, 1.9.0 and 1.10.0. Download it from [GitHub releases](https://github.com/wc3mods/war3x/releases).
